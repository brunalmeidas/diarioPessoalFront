# Diário Pessoal

Registre seus momentos e reflexões diárias. Seu espaço pessoal para expressar seus sentimentos.

## 🎯 Sobre o Projeto

Este é um projeto de diário pessoal desenvolvido com React e Vite. Permite criar, editar e excluir entradas do seu diário, com todas as informações salvas localmente no navegador.

## ✨ Funcionalidades

- ✅ Criar novas entradas no diário
- ✅ Editar entradas existentes
- ✅ Excluir entradas
- ✅ Visualizar todas as entradas em formato de cards
- ✅ Dados salvos automaticamente no navegador (localStorage)
- ✅ Interface responsiva e amigável
- ✅ Design moderno com efeito glassmorphism
- ✅ Background temático com código binário

## 🛠️ Tecnologias Utilizadas

- **React** - Biblioteca JavaScript para construção de interfaces
- **Vite** - Ferramenta de build rápida para desenvolvimento
- **CSS** - Estilização da aplicação com efeitos modernos
- **localStorage** - Armazenamento local dos dados

## 📦 Como Instalar

1. Certifique-se de ter o Node.js instalado (versão 16 ou superior)

2. Clone ou baixe este repositório

3. Abra o terminal na pasta do projeto e instale as dependências:
```bash
npm install
```

## 🚀 Como Executar

Para iniciar o servidor de desenvolvimento:
```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173`

Para criar uma versão de produção:
```bash
npm run build
```

Para visualizar a versão de produção:
```bash
npm run preview
```

## 💡 Como Usar

1. Digite um título para sua entrada
2. Escreva o conteúdo da sua entrada no campo de texto
3. Clique em "Adicionar Entrada" para salvar
4. Para editar uma entrada, clique no botão "Editar"
5. Para excluir uma entrada, clique no botão "Excluir"

## 📝 Notas

- Os dados são salvos apenas no navegador local
- Se você limpar os dados do navegador, as entradas serão perdidas
- Este é um projeto de aprendizado, desenvolvido com foco em simplicidade
